# Testing Face-System-Inc

## Prerequisites

- Python 3.12+
- `pip install -r requirements.txt`
- `pip install onnxruntime` (not listed in requirements.txt but required by insightface)
- InsightFace models auto-download on first run to `~/.insightface/models/buffalo_l/`

## Running the Server

```bash
cd /path/to/Face-System-Inc
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

- First startup may be slow (~15s) due to insightface model loading
- Server runs on CPU by default (ignore CUDA warnings)
- If port 8000 is in use: `fuser -k 8000/tcp` then retry

## Key API Endpoints

| Endpoint | Method | Description |
|---|---|---|
| `/platforms` | GET | List all supported social media platforms |
| `/search/social?username=X` | GET | Search all platforms for a username |
| `/search/social?username=X&platforms=GitHub,Twitter` | GET | Search specific platforms only |
| `/add` | POST | Add a person (requires image file + person_id) |
| `/search` | POST | Search for face matches (requires image file) |
| `/docs` | GET | Swagger UI (auto-generated by FastAPI) |

## Testing Social Media Search (No Face Image Needed)

The social media search endpoints (`/search/social`, `/platforms`) work independently of the face recognition system and don't require image files.

```bash
# List all platforms
curl -s http://localhost:8000/platforms | python3 -m json.tool

# Search a known username on a specific platform
curl -s "http://localhost:8000/search/social?username=torvalds&platforms=GitHub" | python3 -m json.tool

# Test SSRF validation (should return error)
curl -s "http://localhost:8000/search/social?username=evil.com%23" | python3 -m json.tool

# Test with invalid platform names (platforms_checked should only count valid ones)
curl -s "http://localhost:8000/search/social?username=torvalds&platforms=GitHub,FakePlatform" | python3 -m json.tool
```

## Testing Face Endpoints

Face endpoints (`/add`, `/search`) require a valid image file with a detectable face:

```bash
curl -X POST "http://localhost:8000/add?person_id=test_user" -F "file=@photo.jpg"
curl -X POST "http://localhost:8000/search" -F "file=@photo.jpg"
```

## Common Issues

- **`ModuleNotFoundError: No module named 'onnxruntime'`**: Run `pip install onnxruntime`
- **`[Errno 98] address already in use`**: Kill existing process with `fuser -k 8000/tcp` or use a different port
- **CUDA warnings**: Safe to ignore — the app falls back to CPU automatically
- **Slow first startup**: Normal — insightface loads 5 ONNX models on startup

## Devin Secrets Needed

None — the application runs locally with no authentication required.
